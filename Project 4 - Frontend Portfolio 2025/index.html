About Me

I’m Saydul — a Front-End Web Developer based in Birmingham. I’m passionate about crafting beautiful, accessible, and high-performance web experiences using modern technologies. With a strong foundation in HTML, CSS, JavaScript, and responsive design, I specialise in translating designs into clean, maintainable code and creating user-friendly, mobile-optimised websites. My journey into web development is shaped by my background in biological sciences, where I honed analytical thinking and problem-solving skills — qualities I now bring to every development challenge. Whether converting a Figma design into code, fixing layout issues, or adding interactivity, I focus on performance, accessibility, and pixel-perfect detail.
